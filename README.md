# Students Attendance Management System

## Project Description

Students Attendance Management System is a Python-based application developed to manage student attendance records.

The system allows users to add, search, view, update, and delete attendance records. All attendance data is stored in an Excel file using the OpenPyXL library.

## Features

- Add student attendance
- Search student records
- Find attendance records
- Update attendance records
- Delete attendance records
- Show all attendance records
- Clear form data
- Store records in Excel
- Simple and user-friendly GUI

## Technologies Used

- Python
- Tkinter
- OpenPyXL
- Excel

## Data Fields

The system stores:

- Record ID
- Student ID
- Student Name
- Class
- Date
- Subject
- Attendance Status

## File Structure

- `attendance.py` - Main Python program
- `attendance_records.xlsx` - Excel file containing attendance records
